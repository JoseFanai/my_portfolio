# Personal Developer Portfolio </>

Welcome to my personal web developer portfolio! This repository contains the source code for my portfolio website, designed to showcase my skills, projects, and professional experience in web development.

[![Live Demo](https://img.shields.io/badge/demo-Live%20View-success)](https://portfolio-josefanai.netlify.app/)

## 👨‍💻 About
I am a passionate Web Developer specializing in building interactive, responsive, and user-friendly web applications. This portfolio serves as a digital resume and a centralized place to view my journey in software development.

## ✨ Features
* **Projects Showcase:** Detailed cards for my recent works (including the Student Report Card System).
* **Experience Section:** Highlights of my professional internships, including my frontend work on the live MSMC project.
* **Functional Contact Form:** Integrated with **Formspree** to allow visitors to send messages directly to my email without needing a backend server.
* **Skills Summary:** A visual representation of my technical toolkit.
* **Responsive Design:** Fully optimized for seamless viewing across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend Service:** Formspree (for form handling)
* **Tools & Version Control:** Git, GitHub, VS Code
